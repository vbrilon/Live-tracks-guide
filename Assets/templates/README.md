# Templates (placeholders)

This folder holds starter templates referenced by the docs. Replace these placeholders with your own files when ready:

- `XR18_Performance.scn` — XR18 Scene mapping ch 13–18 to USB 13–18, Main LR OFF on 13/14, Buses set per your IEM plan.
- `XR18_Break.scn` — XR18 Scene mapping ch 17/18 to USB 1/2 for break music; ch 1/2 Source = Analog (or muted).
- `Ableton_LiveTracks_Template.als` — Ableton set pre‑routed: Click/Cues/Tracks 1–4 to Ext. Out 13–18; optional Bass/Guitar/Keys to 6/7/12; Warp Off; Global Quantization 1 Bar.
- `Reaper_LiveTracks.rpp` — Reaper template with tracks named `13_Click`, `14_Cues`, `15_TracksA`… and Region Render Matrix presets.

Note: Files here are placeholder text so the repo stays small. Export your real `.scn` / `.als` / `.rpp` and overwrite these paths to wire templates into the docs.
